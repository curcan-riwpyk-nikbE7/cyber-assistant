# Архитектурный план: Десктопное приложение «КИБЕР» (Cyber Assistant)

Полноценное настольное приложение для Windows с гибридным режимом работы (Интернет + Офлайн), живым анимированным маскотом, системным треем и прямым контролем оконной системы Windows.

---

## 1. Концепция: Гибридный режим (Online + Offline)

Ассистент не зависит от одного источника — он работает по **двухконтурной системе**:

```
                              [ Голос пользователя ]
                                         │
                                         ▼
                             [ Модуль захвата аудио ]
                                         │
               ┌─────────────────────────┴─────────────────────────┐
               ▼                                                   ▼
     [ При наличии Интернета ]                           [ Без Интернета (Офлайн) ]
  • Быстрый поиск в сети (новости,                   • 100% локальное распознавание
    погода, YouTube, ответы на любые темы)             через faster-whisper (CUDA)
  • Облачный ультрабыстрый LLM                       • Управление окнами, звуком,
    (Gemini / Groq / OpenRouter)                       запуском софта через WinAPI
  • Сверхреалистичный синтез речи (Edge-TTS)         • Локальная Ollama (Qwen 2.5)
```

---

## 2. Модуль прямого управления Windows («Руки Кибера»)

Кибер получает прямой доступ к интерфейсам **Windows API (через ctypes и Win32)**:

### А. Управление окнами и рабочим столом:
* **«Сверни всё» / «Покажи рабочий стол»:** системный вызов эмуляции `Win + D`.
* **«Сверни это окно»:** определение текущего активного окна и его сворачивание (`ShowWindow SW_MINIMIZE`).
* **«Разверни окно на весь экран»:** перевод в `SW_MAXIMIZE`.
* **«Закрой программу»:** отправка системного сигнала `WM_CLOSE` активному приложению.
* **«Переключи на [название]»:** поиск окна по имени и вывод на передний план (`SetForegroundWindow`).

### Б. Управление браузером и интернетом:
* **«Открой браузер»:** запуск Chrome / браузера по умолчанию.
* **«Найди в интернете [запрос]»:** мгновенный поиск в Google/Яндекс.
* **«Открой YouTube и найди [музыку/видео]»:** открытие поисковой выдачи YouTube.
* **«Закрой вкладку» / «Новая вкладка»:** эмуляция хоткеев браузера.

### В. Мультимедиа и системный звук:
* **«Сделай звук на 50%»:** прямое выставление системной громкости через `pycaw`.
* **«Заглуши звук» / «Включи обратно»:** мгновенный Mute/Unmute.
* **«Пауза / Плей / Следующий трек»:** отправка аппаратных кодов мультимедиа-клавиш.

## 3. Архитектура настольного приложения

Приложение строится без тяжелого Electron, на базе нативного движка **Edge Chromium WebView2**:

```text
cyber-assistant/
├── app.py                 # Главное десктопное окно приложения (WebView2)
├── tray.py                # Иконка в системном трее Windows (возле часов)
├── overlay.py             # Всплывающий прозрачный мини-виджет поверх игр
├── core/
│   ├── listener.py        # Захват аудио, VAD (фильтр тишины), faster-whisper
│   ├── speaker.py         # Озвучка ответов (TTS) с кэшированием фраз
│   ├── router.py          # Моментальный роутер системных команд (10 мс)
│   └── brain.py           # Интеллект: интернет-поиск + LLM
├── tools/
│   ├── window_manager.py  # Сворачивание, разворачивание, закрытие окон
│   ├── browser_tools.py   # Поиск в сети, YouTube, открытие сайтов
│   ├── system_audio.py    # Управление громкостью WinAPI
│   ├── app_launcher.py    # Авто-поиск и запуск установленных игр и программ
│   └── telemetry.py       # Мониторинг нагрузки CPU, RTX 5060, RAM, диска C
├── ui/                    # Интерфейс живого маскота
│   └── index.html         # Маскот, плеер, телеметрия, настройки
├── config.yaml            # Пользовательские настройки и конфигурация
└── pyproject.toml         # Зависимости проекта
```

## 4. Этапы реализации

| Этап | Задача | Результат |
| :--- | :--- | :--- |
| **Этап 1** | **Модули окон и браузера (`window_manager.py`, `browser_tools.py`)** | Команды: свернуть окно, свернуть всё, открыть браузер, найти в интернете, открыть YouTube, закрыть окно. |
| **Этап 2** | **Десктопное приложение и Трей (`app.py`, `tray.py`)** | Окно без рамок браузера, сворачивание в трей при закрытии, меню правого клика. |
| **Этап 3** | **Двусторонний мост Python ⇄ UI** | Маскот шевелит ртом в такт голосу, меняет мимику от исхода команд, отображает реальную телеметрию. |
| **Этап 4** | **Слух и Синтез речи (STT + TTS)** | Постоянное фоновое прослушивание слова «Кибер» и хоткей `Alt + Space`. |
| **Этап 5** | **Коммит в GitHub и сборка `.exe`** | Публикация готовой стабильной версии в ваш репозиторий. |
