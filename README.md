# Cyber Assistant 🟢

> **Персональный голосовой ИИ-ассистент для Windows с живым эмоциональным маскотом и глубоким управлением системой.**

Разработано для **KINGSAID** с поддержкой аппаратного ускорения NVIDIA CUDA (RTX 5060).

---

## 🌟 Ключевые возможности

* **Живой эмоциональный маскот («Кибер»):**
  * Интерактивный персонаж, чьи глаза в реальном времени следят за курсором мыши.
  * Естественная анимация дыхания, моргания и адаптивная смена эмоций в зависимости от контекста диалога (радость, сосредоточенность, неловкость: *«Ну... почти, сэр»*).
* **Мгновенное распознавание речи (STT):**
  * Локальный запуск `faster-whisper` на CUDA (отклик ~160 мс) с отсечением фонового шума через Silero VAD.
  * Реакция на ключевое слово **«Кибер»** (Wake-word) либо вызов по горячей клавише `Alt + Space`.
* **Быстрое управление Windows:**
  * Управление системным звуком (WinAPI / `pycaw`).
  * Мультимедиа-контроль (плей, пауза, следующий трек в Spotify / Яндекс Музыке / браузере).
  * Запуск и закрытие любых установленных программ (Steam, Discord, браузер, терминал).
  * Системный мониторинг в реальном времени (нагрузка CPU Ryzen 5600X, GPU RTX 5060, RAM, диск C).
* **Умный диалоговый режим (LLM):**
  * Поддержка как локальных моделей через Ollama (`qwen2.5:7b`, `llama3.1:8b`), так и облачных API.
* **Синтез речи (TTS):**
  * Реалистичный нейросетевой голос на русском языке без роботизированного скрежета.

## 📁 Структура проекта

```text
cyber-assistant/
├── core/                  # Ядро ассистента
│   ├── listener.py        # Захват аудио, VAD и faster-whisper
│   ├── speaker.py         # Синтез и воспроизведение речи (TTS)
│   ├── router.py          # Маршрутизатор быстрых системных команд
│   └── brain.py           # Связка с LLM и Function Calling
├── tools/                 # Системные модули управления Windows
│   ├── system_audio.py    # WinAPI громкость и Mute
│   ├── app_launcher.py    # Запуск и переключение приложений
│   ├── media_control.py   # Хоткеи мультимедиа
│   └── telemetry.py       # Мониторинг процессора, видеокарты и диска
├── ui/                    # Живой интерактивный интерфейс
│   ├── index.html         # Маскот, плеер, телеметрия и дашборд
│   └── mascot.js          # Физика глаз, мимики и эмоций
├── config.yaml            # Пользовательские настройки и конфигурация
├── run.py                 # Главная точка входа
└── pyproject.toml         # Зависимости и пакетный менеджер (uv)
```

## 🚀 Быстрый старт

### Требования:
* Windows 10/11 x64
* Python 3.12+
* Пакетный менеджер `uv`

### Установка зависимостей:
```bash
uv sync
```

### Запуск:
```bash
python run.py
```
