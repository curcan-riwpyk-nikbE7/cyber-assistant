>_ Справочник голосовых команд

Команды, которые Кибер выполняет напрямую без задержек

🗔 Управление окнами

• «Кибер, сверни всё» — открывает рабочий стол (Win+D)
• «Кибер, сверни это окно» — минимизирует активную программу
• «Кибер, разверни на весь экран» — разворачивает окно
• «Кибер, закрой программу» — безопасное закрытие (Alt+F4/WM_CLOSE)

🌐 Интернет и Браузер

• «Кибер, найди в интернете [запрос]» — быстрый поиск Google/Яндекс
• «Кибер, найди на ютубе [видео]» — мгновенный поиск на YouTube
• «Кибер, открой ютуб» — запуск главной страницы YouTube

🎮 Программы и Игры

• «Кибер, запусти Steam» — запуск Steam клиента
• «Кибер, открой Discord» — запуск Discord
• «Кибер, открой Telegram» — запуск Telegram Desktop

🎵 Звук и Мультимедиа

• «Кибер, пауза / плей» — переключение трека
• «Кибер, следующий трек» — перелистывание песни
• «Кибер, статус системы» — сводка температуры и нагрузки ПК
