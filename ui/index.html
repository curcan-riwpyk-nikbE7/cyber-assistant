⚡ Сценарии и Автоматизация

Готовые пакетные цепочки действий для работы и игр

☀️ Утренний брифинг

Кибер проверит состояние системы, свободное место на диске, озвучит точное время и пожелает отличного дня.

Голос: «Кибер, брифинг»

💼 Режим разработки

Разворачивает браузер, открывает рабочие сервисы и фокусирует окно для максимальной продуктивности.

Голос: «Кибер, режим работы»

🎮 Игровой режим

Сворачивает фоновые окна, запускает клиент Steam и оптимизирует звук.

Голос: «Кибер, игровой режим»

🧹 Очистить экран

Мгновенно сворачивает все активные окна и переходит на чистый Рабочий стол.

Голос: «Кибер, сверни всё»

📱 Telegram Companion (Astra Connect)

Управляйте компьютером прямо с телефона из Telegram: делайте скриншоты экрана (/screen), проверяйте статус железа (/status) и передавайте голосовые реплики.

🔊 Core Audio (Управление громкостью)

Прямой доступ к звуковой подсистеме Windows через pycaw: плавная регулировка, точные проценты, отключение звука (Mute).

● Встроен

🌐 Web Search & YouTube

Быстрый поиск информации в сети и мгновенный запуск любого видео или музыки на YouTube по названию.

● Встроен
